# Game Design Document (черновик)

## Концепция

Top-down 2D roguelite про бесконечное процедурное подземелье. Цель — не "выйти",
а спуститься и узнать, что находится на самом дне.

## Игровой цикл

Explore → Fight → Loot → Upgrade → Discover → Descend Deeper

## Ключевые механики

- **Освещение**: фонарь с ограниченным радиусом; лучшие лампы/масло/магический свет
  позволяют безопаснее исследовать глубокие уровни.
- **Нелинейность**: верёвки, лестницы, лифты, шахты, секретные проходы и шорткаты
  между этажами. Прогресс = исследование, а не просто "дойти до выхода".
- **Безопасные зоны**: лагеря, поселения, торговцы, кузнецы — крафт, апгрейд,
  квесты, подготовка перед спуском.
- **Биомы**: лабиринты, пещеры, руины, шахты, скрытые цивилизации (расширяется по мере разработки).
- **Прогрессия**: персистентная прокачка персонажа между забегами (roguelite, не roguelike).
