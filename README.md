# Dungeon Crawler — Infinite Roguelite

Top-down 2D roguelite: бесконечный процедурный подземный мир, динамическое освещение
(фонарь + туман войны), нелинейное исследование этажей, крафт, прогрессия персонажа,
и в перспективе — онлайн-мультиплеер.

Основной цикл: **Explore → Fight → Loot → Upgrade → Discover → Descend Deeper**

## Стек

- **client/** — игра: HTML5 Canvas + JavaScript (рендеринг, генерация подземелий, бой, UI).
  Работает полностью в браузере, сервер на старте не обязателен.
- **server/** — Java (Spring Boot): аккаунты, сохранения в облаке, лидерборды,
  в будущем — realtime-мультиплеер через WebSocket. Подключается позже, не блокирует разработку клиента.
- **shared/** — форматы данных и протоколы, общие для клиента и сервера (JSON-схемы, документация протокола).

## Быстрый старт (клиент)

```bash
cd client
npm install
npm run dev
```

## Быстрый старт (сервер, опционально на данном этапе)

```bash
cd server
./mvnw spring-boot:run
```

## Статус

Ранняя стадия — скелет проекта. Движок/технологии могут поменяться, структура спроектирована
так, чтобы замена рендер-слоя или бэкенда не требовала переписывать игровую логику
(см. принципы разделения в `docs/ARCHITECTURE.md`).
