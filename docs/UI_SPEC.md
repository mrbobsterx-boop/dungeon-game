# UI — референс и решения

Основано на референс-скриншотах (стиль тёмный камень + золотая рамка, painterly-арт
персонажа). Точные цифры/иконки — не финал, менять свободно; фиксируем только
**структуру экранов**, чтобы код и данные были готовы под неё.

**Карты/миникарты не будет** — этот экран сознательно исключён из UI и из кода
(нет `MinimapUI.js`, нет слоя карты).

## Экраны

| Экран | Файл | Показывает |
|---|---|---|
| HUD (поверх игры) | `ui/HUD.js` | портрет+уровень, HP/MP полоски, золото, ключи, топливо фонаря (%), хотбар 1-0, способности Q/E |
| Инвентарь | `ui/InventoryUI.js` | сетка предметов с фильтрами по категориям, рамка цвета редкости, быстрые ячейки |
| Персонаж | `ui/CharacterUI.js` | папердолл-экипировка (13 слотов), первичные атрибуты, вторичные боевые характеристики, сопротивления по 6 стихиям |
| Навыки | `ui/SkillsUI.js` | дерево по вкладкам-категориям, узлы с рангами, требуют пререквизит + уровень |
| Квесты | `ui/QuestsUI.js` | вкладки активные/завершённые/провальные, группы главный/побочный/фракционный, цели с чекбоксами, награды |
| Главное меню | `ui/MenuUI.js` | продолжить/новая игра/загрузить/настройки/достижения/выход |

| Лагерь | `ui/CampUI.js` | 6 плиток: отдохнуть / создать предмет / приготовить еду / сварить зелья / улучшить снаряжение / починить снаряжение + выход |
| Крафт (общий для предметов/еды/зелий) | `ui/CraftingUI.js` | категории слева, список рецептов, деталь (иконка/редкость/описание/требования "есть/нужно"), счётчик количества, рюкзак справа |

## Лагерь и крафт

Лагерь ставится игроком в любой точке подземелья (`systems/CampSystem.js`), а не
привязан к фиксированным безопасным зонам — в отличие от поселений (см. ниже).
Пока лагерь активен, зона временно безопасна.

Один движок крафта (`systems/CraftingSystem.js` + `data/recipes.json`) обслуживает
все три экрана лагеря — "предмет"/"еда"/"зелья" — они лишь фильтруют рецепты
по полю `kind`. Улучшение и починка снаряжения — отдельные системы
(`EquipmentUpgradeSystem.js`, `EquipmentRepairSystem.js`), т.к. работают не с
рецептами, а с `durability`/`upgradeLevel` конкретного предмета (`items/Item.js`).

## Мир: контейнеры и поселения

- **Контейнеры** (сундуки/бочки/мешки — `entities/props/Container.js`) — одноразовый
  интерактивный лут, расставляется `world/dungeon/PropPlacer.js` при генерации этажа.
- **Поселения** — крупные фиксированные безопасные зоны с несколькими NPC/торговцами,
  генерируются вместе с этажом (`world/dungeon/SettlementGenerator.js`), в отличие
  от лагеря — не ставятся игроком и не переносятся.



**Первичные атрибуты** (`StatsComponent`): сила, ловкость, выносливость, интеллект, вера.

**Вторичные боевые характеристики** (считает `systems/StatsSystem.js`, UI не считает сам):
урон, защита, шанс крит. удара, скорость атаки, скорость движения, вампиризм, уклонение,
сопротивление (общее число).

**Сопротивления по стихиям** (`ResistancesComponent`): огонь, холод, молния, яд, свет, хаос.

**Валюты** (`data/currencies.json`): золото, ключи, топливо фонаря (% — тратится со
временем, отдельно от предметов-масла в инвентаре, которые его пополняют).

## Экипировка

13 слотов (`items/Equipment.js`): шлем/плащ/доспех/перчатки/ботинки (броня),
амулет/2 кольца/пояс/источник света (аксессуары), оружие/щит/доп. оружие.

## Редкость предметов

`items/ItemRarity.js`: common → uncommon → rare → epic → legendary, каждая со своим
цветом рамки иконки в инвентаре.

## Дерево навыков

`data/skills.json`: категории-вкладки (бой/ловкость/выживание/магия/поддержка),
узлы с максимальным рангом, разблокировка через `requires` (id узла-пререквизита).
Логика открытия — в `systems/SkillTreeSystem.js`.

## Квесты

`data/quests.json`: тип (main/side/faction), список целей с id и текстом,
награды (золото/самоцветы/предметы). Прогресс и выдача наград — в `systems/QuestSystem.js`.
